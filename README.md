# Синапс — песочница synaps.bond

Одностраничный сайт: демонстрация турбота для турфирм + цены + контакты.

## Файлы

| Файл | Что |
|---|---|
| `index.html` | главная: hero, демо чата, выгоды, процесс, цены, вопросы, контакты |
| `style.css` | оформление (тёмная тема, адаптив) |
| `app.js` | демо турбота (симуляция) и анимации |
| `privacy.html` | политика конфиденциальности |
| `404.html` | страница для несуществующих адресов |

## Правки

Данные демо-туров — в `app.js`, объект `TOURS`. Тексты — в `index.html`.
После правки: коммит и push в GitHub, Cloudflare Pages соберёт сам.

## Публикация

Репозиторий подключается к Cloudflare Pages: фреймворк None, команда сборки пустая, каталог вывода `/`.
